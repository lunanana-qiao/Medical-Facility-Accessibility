# 社区医疗设施可达性与公平性评价

> 基于多源大数据的城市社区医疗设施（社区卫生服务中心 / 服务站）空间可达性与公平性测度，以及供需匹配与配置优化分析。

以高德步行路径、人口栅格、社区/街道/片区三级行政区划等多源数据为基础，采用**高斯两步移动搜索法（Gaussian 2SFCA）**测度医疗设施可达性，并以**基尼系数 / 洛伦兹曲线**评价资源配置公平性，最终输出 5 / 10 / 15 分钟生活圈服务率与空间分异结果。

---

## 项目目标

- 测度社区医疗设施的空间可达性（区分步行 / 骑行，社区 / 街道 / 片区三级尺度）；
- 评价医疗资源配置的公平性（基尼系数 + 洛伦兹曲线）；
- 计算 5 / 10 / 15 分钟等时圈内服务人口覆盖率（服务率）；
- 支撑医疗设施供需匹配分析与选址优化。

## 核心算法

### 1. 高斯两步移动搜索法（Gaussian 2SFCA）

- **第一步**（供需比）：以医疗设施为中心，用高斯衰减函数 `G(d) = (e^(-0.5·(d/d₀)²) − e^(-0.5)) / (1 − e^(-0.5))` 对服务范围内人口加权，计算设施供给规模与需求人口的供需比 `A_i`；
- **第二步**（可达性）：以需求点（社区质心 / 渔网点）为中心，反向累加周边设施的供需比，得到需求点可达性值。

### 2. 公平性评价

- 按可达性升序排列人口，绘制洛伦兹曲线；
- 计算基尼系数 `Gini = X / (X + Y)`，其中 `X` 为公平曲线与洛伦兹曲线围合面积、`Y` 为洛伦兹曲线下方面积。

### 3. 服务率计算

- 基于等时圈（5 / 10 / 15 分钟）判断栅格人口点是否被社区卫生服务中心 / 服务站覆盖；
- 按片区、街道、社区三级汇总服务人口与服务率。

## 代码结构

```
eve_data.py   数据模型类（设施 / 社区 / 片区 / 街道 / 供需比计算单元）
final.py      主流程：路径获取、可达性计算、公平性、服务率统计
```

`final.py` 主要函数：

| 函数 | 功能 |
| --- | --- |
| `gaode_dist()` | 高德 API 批量获取社区—设施步行距离与耗时 |
| `gaosi_shequ()/jiedao()/qixing_*()` | 高斯 2SFCA 可达性计算（步行/骑行 × 社区/街道） |
| `gongping()` | 基尼系数 + 洛伦兹曲线公平性分析 |
| `serve_people()` | 5/10/15 分钟等时圈服务率统计（三级行政区划） |
| `filter()/filter2()` | 15 分钟可达候选点 / 服务站筛选 |

## 快速开始

```bash
# 1. 安装依赖

# 2. 配置高德 API Key（勿硬编码在代码中）
#    将 final.py 中的 key 替换为环境变量：AMAP_KEY
export AMAP_KEY="your_key"

# 3. 运行主流程
python final.py
```

## 项目背景

本人参与东南大学交通学院健康与发展研究项目《基于多源数据的社区医疗设施布局供需特征研究》（部分成果已发表《基于多源数据的城市边缘区社区医疗设施可达性测度》，测绘通报 2025 年 S2 期（第三作者）），研究方向为城市公共服务设施可达性与公平性，本目录为该研究的核心算法实现（Python 编程）。
